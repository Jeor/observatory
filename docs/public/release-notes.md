# 0.1.0 release candidate

First public-source candidate. Includes Docker packaging, single-owner authentication for live network access, configurable calendar time zones, account-scope protection, bounded artwork fetching, and isolated release verification.

Images and screenshots shipped in the repository use synthetic/demo data. No viewing records, upstream credentials, or private deployment configuration are distributed.

This version reads recent saved playback state and hourly NNTP download statistics. It does not reconstruct complete watch sessions. See README for connector contracts and migration from the private prototype.
